# Threats to Validity

## Observation is not biology

Connectomics datasets contain segmentation, detection, proofreading and boundary errors. FCR must distinguish compression of *the dataset representation* from compression of the underlying biological circuit.

## Boundary censoring

Neurites leave the imaged volume. A missing edge can mean "outside the observed volume" rather than "biologically absent." Primary analyses require explicit eligibility rules.

## Negative sampling

Because true non-connections vastly outnumber connections, bits-per-positive can be manipulated by the candidate set. Always report bits per candidate pair and sensitivity to candidate construction.

## Shared-node leakage

Random edge splits allow the same neurons to appear in train and test. This can make cell identity or local geometry a shortcut. The primary test is spatially disjoint.

## Model-cost laundering

A giant model cannot be treated as free. Report residual bits and model bits. For mature experiments use a defensible MDL/prequential code.

## Hyperparameter leakage

Do not tune on the final spatial test block. Freeze architecture, candidate definition, and primary metric before test evaluation.

## Functional circularity

Do not rank residuals using the same functional target used to score reconstruction. That creates an oracle. Functional measurements are evaluation-only unless an experiment explicitly studies a supervised codec and labels it as such.

## Synthetic-data overinterpretation

Synthetic experiments prove software properties, not neuroscience. A result generated by assumptions built into the simulator is not evidence for H1–H3.

## Connectome sufficiency

Even perfect synaptic wiring may omit molecular state, receptor composition, neuromodulation, membrane properties, gene expression, glial dynamics and transient activity. FCR therefore speaks about preservation of defined observables, not preservation of an entire person or brain state.

## Novelty uncertainty

Related ideas exist across MDL, graph compression, generative connectomics, predictive coding and rate-distortion. The project name and formulation must not be advertised as unprecedented without a systematic literature/patent review.
